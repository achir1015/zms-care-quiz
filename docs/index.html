資料助秘照顧服務員學科測驗

照顧服務員單一級技術士學科測驗練習。內建題庫與 104～115 年學科測試試題共 897 題， 每次 100 題、選項隨機換位置，每一題都有 AI 解說，還能用自然語音朗讀。

📝 開始使用線上版 🎧 語音教學 ⬇ 下載電腦版

功能

📚內建 897 題

106／114／115 年版學科題庫、114 參考題庫、104～115 年度學科測試試題合併，不用匯入就能練習。

🔀選項隨機換位置

題庫的 (A) 出題時可能變成 (B)，正確答案跟著變，避免背答案位置。

💡每題 AI 解說

為什麼對、其他選項錯在哪、記憶小訣竅，交卷後和單元複習都看得到。

🔊自然語音朗讀

題目、正確答案和解說都能念給你聽，通勤時也能用聽的複習。

📝四種測驗方式

模擬測驗（依單元比例 100 題）、單元練習、歷屆試題、錯題複習。

📈成長圖表

每次分數折線圖、各單元答對率、最常答錯的題目。

下載與使用

平台使用方式
🌐 線上版直接開啟，手機、平板、電腦都能用；可「加到主畫面」，離線也能練習。紀錄存在這台裝置。
🪟 Windows 11下載安裝檔 ZMSCareQuiz-Setup-版本.exe，可匯入新年度學科測驗 PDF、多位學員帳號與權限。
🍎 macOS下載 DMG，拖到「應用程式」即可（已通過 Apple 公證）。

線上版的朗讀用瀏覽器內建語音：用 Microsoft Edge 開啟有「曉臻（自然）」語音最自然；iPhone／iPad 可在「設定 → 輔助使用 → 朗讀內容 → 聲音」下載「美佳（增強版）」。
